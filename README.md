## 📖 这是什么仓库？

这是我本科阶段的 **个人编程作品集**。它会跟着我一整个学期（16 周）一起长大：

- 每周的**实验与作业** → 放在 `labs/weekXX/`
- 课堂**笔记与心得** → 放在 `notes/`
- 课程之外的**自主项目** → 放在 `projects/`
- 踩过的**坑与解决办法** → 放在 `docs/`

它同时也是一份**公开的学习日记**：任何老师、同学或招聘者点开这个链接，
都能看到我这一学期学了什么、做了什么、走了多少弯路。

## 🚀 快速上手

### 第一次使用（克隆这个仓库到本地）

```bash
# 1. 复制仓库地址，替换下面的 <你的GitHub用户名>
git clone https://github.com/<你的GitHub用户名>/ncu-human-ai-programming.git

# 2. 进入仓库
cd ncu-human-ai-programming
```

### 每周开始新工作

```bash
# 1. 拉取老师或同学的最新更新
git pull

# 2. 开始写本周的代码……

# 3. 存档：把改动记录成一次"提交"
git add .
git commit -m "week01: 完成第一次环境配置"

# 4. 上传到 GitHub
git push
```

> 💡 `commit -m` 后面那句话写什么，就是这次存档的"名字"。
> 起个好名字，三个月后你自己就能看懂历史记录。

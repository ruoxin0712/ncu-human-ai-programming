## 实验内容

研究**非线性阻尼单摆**的运动规律。对应微分方程：

```
d²θ/dt² = -(g/L)·sin(θ) - b·dθ/dt
```

| 符号 | 含义 | 默认值 |
| :--- | :--- | :--- |
| θ | 摆角 | 待填写 |
| g | 重力加速度 | 9.81 m/s² |
| L | 摆长 | 1.0 m |
| b | 阻尼系数 | 0.0（退化为理想单摆） |
| ω | 角速度 | 0.0 rad/s |

观测量：θ(t) 时间序列、总能量 E(t)、相图 (θ, ω) 轨迹。

完整参数与设计意图见 [`metadata.yaml`](metadata.yaml)。

### 实时参数控制面板

| 参数 | 范围 | 默认 | 步长 | 作用 |
| :--- | :--- | :--- | :--- | :--- |
| 摆长 `L` | 100 ~ 350 px | 200 px | 1 px | 改变固有周期 `T = 2π√(L/g)` |
| 重力 `g` | 1 ~ 25 m/s² | 9.8 | 0.1 | 同上；`g` 越大摆得越快 |
| 阻尼 `b` | 0.000 ~ 0.010 | 0.0030 | 0.0001 | 阻尼强度，0 表示无阻尼理想单摆 |

**阻尼量的约定（重要）**

运动方程为 `θ″ = −(g/L)·sin θ − γ·θ′`，其中衰减率 `γ = 60·b`。

也就是说 `b` 表示**每 1/60 秒损失的速度比例**，这样 `0.000 ~ 0.010` 这一区间
正好覆盖「几乎无阻尼 → 明显衰减」：

| `b` | 等效 `γ` | 振幅衰减时间常数 `τ = 2/γ` |
| :---: | :---: | :---: |
| 0 | 0 | ∞（永久摆动） |
| 0.002 | 0.12 /s | 16.7 s |
| 0.003 | 0.18 /s | 11.1 s |
| 0.005 | 0.30 /s | 6.7 s |
| 0.010 | 0.60 /s | 3.3 s |

振幅按 `A(t) ≈ A₀·e^(−γt/2)` 衰减。HUD 实时显示 `b`、理论周期 `T` 与 `τ`。

> ℹ️ 若把 `b` 直接当作 `γ`（单位 s⁻¹）使用，`b=0.010` 对应 `τ = 200 s`，
> 肉眼几乎看不出衰减，因此引入 `60` 的换算系数。

### 物理与实现要点

- **物理模型**：`θ″ = −(g/L)·sin θ − γ·θ′`，半隐式欧拉法积分，固定子步长 1/600 s
- **像素与物理量的换算**：固定 200 px = 1.00 m，故 `L_m = L_px / 200`
- **初始参数**：L = 200 px（1 m）、g = 9.8 m/s²、θ₀ = 45°、ω₀ = 0
- **周期校验**：小角近似理论值 2.007 s；计入大振幅修正 `T = T₀(1 + θ₀²/16)`
  得 2.085 s，实测 2.087 s，误差 0.1%
- **能量校验**：HUD 显示总能量与相对漂移。无阻尼时 20 s 内漂移有界于 ±0.25%；
  `b=0.010` 时 4 s 衰减 −91.2%，与 `e^(−γt)` 理论值 −91.0% 吻合
- **衰减率标定**：对转折点振幅做 `ln A ~ t` 线性拟合，`b=0.010/0.005/0.002`
  实测衰减率 0.3013 / 0.1505 / 0.0606 s⁻¹，与设计值 0.300 / 0.150 / 0.060 误差 <1%
- **能量基准重置**：改变 `L`/`g` 相当于外部做功，故每次调参或复位都会重置能量基准，
  避免 HUD 出现虚假的"漂移"
- **渲染**：单文件纯原生 Canvas，`requestAnimationFrame` 驱动，DPR 自适应，
  离屏画布分别承担网格背景与发光拖尾，主画布每帧合成

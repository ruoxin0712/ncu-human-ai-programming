# 🚀 个人项目作品集 · Projects

这里放**课程之外的自主项目**——它们是你「作品集」真正的门面。

## 什么算好项目？

一个好的项目不一定要复杂，但要满足这三点：

1. **能跑** —— 别人克隆下来按 README 就能运行起来
2. **能看懂** —— README 说清楚「它解决什么问题、怎么用」
3. **是你自己做的** —— 能讲清楚每个设计决策的来由
